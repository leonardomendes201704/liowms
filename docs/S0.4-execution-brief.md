## Backend ([WMS-94](https://app.plane.so/paperclip-company/browse/WMS-94/))

**ADR-004** + crypto existente `apps/api/src/crypto/envelope.ts` (bootstrap em install).

1. **Migration `004_config_store.sql`**
   - `config_settings`: `tenant_id`, `key`, `value_json`, `updated_at` (RLS tenant)
   - `config_secrets`: `tenant_id`, `key`, ciphertext columns (iv/tag/dek_wrapped), `updated_at` (RLS tenant)
2. **Service** — derive master key from `install_meta` (same as install bootstrap); `sealValue` / `openValue` per secret write/read interno.
3. **API** (tenant admin + RLS):
   - `GET /api/v1/tenant/settings` — merged view: plain settings + secrets as `{ "key", "kind": "secret", "display": "********", "set": true|false }`
   - `PATCH /api/v1/tenant/settings` — upsert plain keys + rotate secrets (never echo cleartext on response)
4. **Higiene** — logs/erros sem valor claro; testes API que export/GET não contém SMTP password.
5. **Tests** — cobertura mínima persistência envelope + RBAC tenant_admin; referência TC-GOLD **J0c-01** (smoke persistência).

Refs: `ADR-004-secrets-envelope-db.md` (brain pack).
